# ARTSCAPE INTERIORS

> *"Elevating spaces with modern luxury, precision & purpose."*  
> Boutique Interior Design Studio • Kondapur, Hyderabad, Telangana, India.

A premium, production-quality web platform for **Artscape Interiors**, an interior design studio based in Kondapur, Hyderabad. Built with React 19, Tailwind CSS v4, Framer Motion, and React Router DOM.

---

## 🌟 Overview & Key Features

- **Architectural Brand Identity**: Built around the Artscape geometric A-frame emblem, champagne gold arcs, and warm ivory aesthetic.
- **Multi-Page Architecture**: Fast, fluid routing powered by React Router DOM v7 across:
  - `/` — **Home**: Hero lighting mood switcher, Before & After transformation slider, Material & Style explorer, services preview, and project timeline estimator.
  - `/about` — **About Us**: Studio philosophy, four core design values, and 4-step execution journey.
  - `/services` — **Services**: All 8 interior design specializations, deliverable checklists, and FAQs.
  - `/gallery` — **Gallery**: Responsive asymmetric masonry portfolio with room filter pills and fullscreen lightbox viewer.
  - `/contact` — **Contact Us**: Interactive inquiry form with URL service prefill, live IST studio open/closed badge, direct phone, WhatsApp fallback, and Kondapur Google Maps embed.
- **Interactive Experience & "WOW Factor"**:
  - **Hero Lighting Switcher**: Switch between morning diffused daylight, sunset warmth, and 2700K cozy evening mood.
  - **Before & After Transformation Slider**: Draggable gold split-view comparison showing the transformation from a raw concrete shell to a finished turnkey home.
  - **Material & Style Lab**: Interactive palettes with real swatches and material textures.
  - **Spatial Scope & Timeline Estimator**: Custom project calculator with 1-click WhatsApp dispatch.
- **Mobile First & Responsive**: Optimized for desktop, laptop scaled viewports (1366x768 to 4K), tablets, and mobile devices (with iOS Safari 16px input zoom prevention).

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/varuntejreddy03/artscape-interiors.git
cd artscape-interiors

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview build locally
npm run preview
```
